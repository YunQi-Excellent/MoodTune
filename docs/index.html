// FEATURES

六个你会在意的能力

意图搜索

不说"关键词"，说"感受"。AI 多路检索 + 精排，从几百首候选里挑出最贴合语境的一小批。

对话式调音

10 段 EQ + 前级。说「低频再轻一点」，AI 基于当前配置微调，参数改了立即听到。

会话隔离

一次听歌场景 = 一个会话。对话、歌单、调音全部独立。切回旧会话一键恢复。

数据本地化

用 File System Access API 同步成 JSON 文件。插件更新、卸载重装，数据不丢。

内置播放器

音频在 offscreen 里播放，侧边栏关了音乐继续。不切回网页版就能听。

OpenAI 兼容

不绑定任何一家。DeepSeek / Moonshot / OpenAI / Ollama 都能接。

// WORKFLOW

Agent 的 4 阶段流水线

LLM 只调用 2 次，中间的检索和过滤全在本地完成

STEP 01
规划

LLM 把需求拆解成检索计划：用哪些工具、什么关键词、目标几首

STEP 02
执行

本地并发调用网易云接口，收集 200-800 首候选

STEP 03
粗筛

按时长/关键词过滤，按来源权重排序，压缩到 60-120 首

STEP 04
精排

LLM 从候选中挑出目标数量，每首附上选择理由

// INSTALL

4 步开始使用

1
克隆仓库
$ git clone https://github.com/yourname/moodtune.git
2
加载扩展

打开 chrome://extensions → 开启开发者模式 → 点击「加载已解压的扩展程序」→ 选择克隆的文件夹

3
配置大模型

点扩展图标打开侧边栏 → 右上角 ⚙️ → 填写 Endpoint / Model / API Key → 保存

4
开始对话

在输入框说「深夜写代码的歌」或「打开调音台」，剩下交给它
