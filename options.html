📁 数据持久化

绑定一个本机文件夹后，插件会把歌单、调音、会话等数据自动同步成 JSON 文件。 更新或重装插件时数据不会丢失。

正在读取…

智能同步：插件里有数据则上传到文件夹；插件为空则从文件夹恢复。自动判断方向。
从文件恢复：强制用文件夹里的数据覆盖插件。适合卸载重装后恢复。

📁 （已绑定目录）/ ├── playlists.json 所有保存的播放列表 ├── eq-presets.json 所有 EQ 预设 ├── sessions/ │ ├── index.json 会话索引（含当前会话 id） │ ├── sess-xxx.json 每个会话的完整数据 │ └── sess-yyy.json └── .meta.json 版本号与最后同步时间

⚠️ 关于卸载：删除插件时，Chrome 不会自动清理你选择的文件夹里的文件。 如需彻底清理，请手动删除该文件夹。

隐私说明：
· API Key 与 endpoint 仅保存在本机 chrome.storage.local。
· 数据文件夹里的 JSON 只包含歌单、调音、会话；不包含 API key。
· 每次「意图搜索」只发送：需求文本 + 候选歌曲的 ID / 名称 / 歌手 / 专辑 / 时长。
· 不发送 Cookie、账号信息、页面 HTML、歌单内容。
· 搜索与歌单读取完全在本地发起，不经过作者服务器。
